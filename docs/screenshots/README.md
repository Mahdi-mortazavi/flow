# اسکرین‌شات‌های Flow

این پوشه برای تصاویری است که در README اصلی نمایش داده می‌شوند. چون رندرِ درستِ
RTL، فونت وزیرمتن و افکت شیشه‌ای فقط روی دستگاه/امولاتور واقعی اندروید ممکن است،
تصاویر باید از همان‌جا گرفته شوند (نه از بیلد ویندوز/وب).

## چه تصاویری لازم است (۴ تا ۵ عدد)

| نام فایل | صفحه | حالت پیشنهادی |
|---|---|---|
| `01-today.png` | امروز | یک روزِ چیده‌شده با تخته‌سنگ، دو کار، یک عادت |
| `02-focus.png` | تمرکز | رینگ کهربایی در وسطِ یک جلسه |
| `03-mirror.png` | آینه | چند شبِ بسته + نمودار کار عمیق |
| `04-onboarding.png` | آنبردینگ | اسلاید اول (نقطه‌ی کهربایی) |
| `05-habit.png` | ساخت عادت | فرمِ «بعد از… این کار را می‌کنم» |

## روش گرفتن

```bash
# با دستگاه متصل یا امولاتور در حال اجرا:
flutter run --release
# سپس در هر صفحه:
adb exec-out screencap -p > docs/screenshots/01-today.png
```

پس از افزودن تصاویر، بخش «پیش‌نمایش» به README اصلی اضافه می‌شود.
